# Security policy

Watchpost is a portfolio and learning project. All bundled data is synthetic, and the live demo is read-only.

## Reporting a vulnerability

If you find a security issue, please report it privately: use GitHub's **Report a vulnerability** button on the Security tab of this repository, or email contact@arterysystems.com.

Please include the affected version, steps to reproduce, and the impact you see. Do not open a public issue for a vulnerability.

You can expect a reply within a few days. Reports are credited in the changelog unless you ask otherwise.
